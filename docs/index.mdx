# Welcome to Zero to Prod

You use software all day. You open websites, send messages, pay for things, ask an AI a question. Somewhere behind every one of those actions is a **backend** — programs on machines you'll never see, storing data, talking to each other, staying up at 3 a.m. This handbook teaches you how to build, run and reason about those systems — starting from wherever you are right now.

**If you can use a computer, you can start here.** You don't need to have written code before. By the end of your track, you'll be able to build a real service, ship it to the cloud, keep it healthy, and explain every decision you made.

## How it's different

- **No gaps.** Every idea climbs the same five-step ladder — an everyday analogy, what actually happens, hands-on, what breaks, and why it's built this way. See [How this handbook works](start/how-this-handbook-works.mdx).
- **One real system.** You build **snip**, a link shortener, and grow it chapter by chapter into something production-shaped: a database, a cache, a queue, containers, Kubernetes, CI/CD, the cloud, monitoring, and AI features.
- **Interactive.** Quizzes that explain every answer, a real Postgres database that runs in your browser, labs on your own laptop, and a progress tracker that saves itself.
- **Ask anything.** Press the **💬 Ask** button (or <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>J</kbd>) on any page to find the sections that answer your question.
- **Free and open, forever.** No sign-up, no paywall. Your progress lives in your own browser.

## Choose your path

Everyone starts with the same foundations (Parts 0–3). Then pick a track — you can switch any time on the [roadmap](/roadmap).

| Track | You'll be able to… | Parts |
|---|---|---|
| 🧱 **Foundations** | Explain how computers, networks, the web, Linux and Git work — and use them confidently. | 0–3 |
| ⚙️ **Backend Engineer** | Design and build APIs, model data, secure and scale services. | 4–8, then 13 & 15 |
| 🚀 **DevOps / Platform Engineer** | Containerise, orchestrate, automate delivery, run infrastructure in the cloud and keep it reliable. | 2, 8–13, 15 |
| 🧠 **AI Engineer** | Build real products on large language models: RAG, agents, evals and running AI in production. | 5–6 basics, 14, 15 |

## How to use each chapter

1. **Read top to bottom once.** Chapters are written to be read in order; each section leans on the one before it.
2. **Do the Lab.** Reading gives you the map; the lab gives you the territory. Every lab is free and runs on your own machine.
3. **Answer the Self-check honestly.** If you can explain the answer out loud, you've got it. If not, reread that section — that's the system working, not you failing.
4. **Mark the chapter complete** at the bottom of the page. Your roadmap fills in as you go.
