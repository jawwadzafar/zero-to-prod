# Glossary

Every term the handbook uses, in plain words, with a link to the chapter that teaches it properly. Terms are added as chapters are written.

## A

**API (Application Programming Interface)**
: A menu of requests one program offers to others: "send me *this*, I'll give you *that*."

## B

**Backend**
: The programs that run on servers, out of sight, doing the work a website or app asks for: storing data, checking passwords, sending emails.

## S

**snip**
: The link-shortener service you build throughout this handbook. Introduced in [0.3 Meet snip](start/meet-snip.mdx).
